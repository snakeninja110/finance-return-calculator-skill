# 中文触发与任务选择

使用语义和上下文匹配，不进行逐字口令匹配。产品词、计算目的、数字或附件可以组合表达；一句话有完整投入、终值和日期，即使没说“理财”也能识别。信息不足不等于没有计算意图：先选任务，再只问必要缺项。

## 常见说法与计算入口

| 需求 | 常见表达 | 处理方式 |
|---|---|---|
| 收益金额/持有收益 | 算收益、赚了多少、实际赚多少、收益几个点、赚几个点、扣完费还剩多少 | 根据本金、收回金额和现金收入计算；分清元和百分比 |
| 折算年化 | 算年化、折合一年多少、年收益率、年化回报、真实年化、到手年化 | 单次投入用 `annualized`；有中途现金流用 `xirr` |
| 定投/追加/分期投入 | 定投收益、多次买入、陆续投入、每月投、分批赎回、内部收益率、IRR、XIRR、irr、xirr | 获取各笔金额与日期；有日期优先现金流 XIRR，不能仅用总投入比值代替 |
| 未来利率情景 | 投进去能赚多少、到期有多少钱、利息多少、年化2%持有90天 | 明确假设利率、期限及费用；有期限的情景用 `projected`，不把参考利率视作真实收益 |
| 保险利益 | 保单收益、分红险收益、增额寿收益、增额终身寿、储蓄险、现金价值、退保能拿多少、利益演示表、利益表截图 | 先确定目标保单年度，读取对应退保价值；规则年缴用 `insurance-table`，非规则现金流用 `xirr` |
| 保险回本 | 几年回本、多久回本、哪年不亏、退保保本、现金价值什么时候超过保费 | 比较表中各年末可取得利益与截至该时点已缴保费，保证与演示分别给结果；规则见下文 |
| 夏普 | 夏普比率、夏普比例、夏普率、夏普值、Sharpe、sharpe ratio | 有等间隔收益用 `sharpe`，有总回报净值可用 `fund-metrics`；不能用最大回撤代替波动率 |
| 波动/回撤 | 年化波动率、波动多大、最大回撤、回撤率、从高点跌了多少、历史最深跌幅 | 明确波动还是峰谷回撤；净值路径可用 `fund-metrics`，回撤适用边界见 [drawdown.md](drawdown.md) |
| 产品比较 | 两个哪个收益高、同样投10万比一下、按3年比较、收益风险一起看 | 确认相同预算、期限及口径后选择比较；不自动解释为购买推荐 |

识别常见口语别称即可，不把任意近似字、OCR错字或同音词强行归类。“几个点”需要按句意分清收益率、百分点差或费用。转换中文数字、万元和百分比时保留原值与归一结果；有歧义先问，不依靠词匹配补数字。

## 上下文续问优先

- “那10年呢”：沿用上文产品及缴费安排，改为10年；保险必须读取第10年对应利益，不能沿用第5年的金额。
- “换成5万”“费用是千分之一”：只更改明确的参数并重算，不重问整套资料。保险利益不能随保费简单按比例放大，除非计划书明确支持比例换算或提供新方案。
- “再算夏普”“回撤也看看”：在现有产品和期间内增加指标，优先复用净值/收益序列；数据不足再问。
- “不算夏普，只看年化”：服从否定和缩小范围的要求，不被“夏普”一词触发。
- “这个呢”并上传图片：已有收益计算语境时先读图；没有上下文且图片无法表明目标时，简短询问是算收益还是查看保障。
- “只看保证的”：只返回保险保证口径，不要求补演示数据。

## 容易混淆的说法

- “年化2%”是用户给出的利率输入，不一定是请求计算年化；结合“投多久/到期多少”识别情景计算。
- “亏了多少”通常是相对成本的持有损益，不直接等同最大回撤；“会不会亏”“稳不稳”属于更广的风险问题，不能仅凭最大回撤或夏普给承诺。
- “预定利率1.75%”“红利实现率100%”是保险材料中的不同指标，不是保单实际年化。
- “回本”可能指退保现金价值覆盖已缴保费，也可能指累计领取覆盖投入。若没有上下文，先确认哪一种；不把身故保险金算作可退保收益。
- “夏普电视”不是 Sharpe；“基金会捐款”不是基金投资；“理财收益计算器网页怎么开发”是开发任务；贷款、房贷、信用卡分期的“实际年化成本”属于借款成本任务，不路由到本 Skill。
- “什么是夏普”“最大回撤什么意思”：可回答概念，只有客户进一步要求算自己产品时才收集数据。
- “这只基金怎么样”“保险怎么买”：意图太宽，不自动选收益计算或启动问卷；结合上下文，必要时问客户希望看收益、风险还是保障。

## 保险回本的输出边界

回本判断是利益表读取与金额比较，属于现有保险分析，不是新的 `action`。每个年度按截至该时点已缴保费计算；有已领取现金时，先核对是否已经包含在演示总利益，避免重复。

只给“已提供年度中首次达到条件的年度”。若表格逐年完整，可报告该范围内首次回本；若只有第5、10年，且第5年不足、第10年达到，则说“第10年已达到，第6至9年缺失，无法确定最早回本年”，不插值或外推。未提供的未来年度不作保证。

例如年缴1万元、交3年、无中途领取，保证退保价值第5年为28000元、第10年为38000元：第5年未覆盖已缴30000元，第10年已覆盖；缺第6至9年时不能称“第10年才回本”。演示口径另行比较并标为非保证。

## 匹配检查示例

| 客户原话 | 应识别的结果 |
|---|---|
| 帮我算下收益呗 | 收益计算意图，收集缺失投入、终值及时间 |
| 10万放90天拿回100800，费都扣了，中途没动过 | 信息充分的 `annualized`，不必再问产品类别 |
| 定投两年赚了3000，实际年化多少 | `xirr`，还缺逐笔投入/收回时间和金额 |
| 夏普比例能算不 | 夏普计算意图，询问收益序列、频率和无风险口径 |
| 这张表哪年退不亏 | 图片利益与已缴保费比较；缺年不报精确首次回本 |
| 回撤20%能算夏普吗 | 说明单独回撤不足，不能替代收益序列及标准差 |
| 那改成10年，只看保证 | 继承保单与缴费参数，取得第10年保证利益 |
| 不要年化，只告诉我赚了多少钱 | 仅算损益，尊重否定范围，不强制年化输出 |
| 帮我写一个基金收益网页 | 开发任务，不启动客户收益问答 |

实际匹配由宿主 AI 的 Skill 发现机制和语义判断执行，本说明不提供独立关键词搜索服务或保证某个命中率。用户无需记住英文技能名。
