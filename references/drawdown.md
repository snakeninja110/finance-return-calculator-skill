# 基金最大回撤的适用条件

## 是否需要询问

| 客户需求 | 是否需要最大回撤 | 需要的信息 |
|---|---|---|
| 持有收益、年化收益率 | 不需要 | 投入、扣费后收回金额、期限 |
| 分次投入/领取的 XIRR | 不需要 | 每笔现金流的金额和日期 |
| 夏普比率 | 不需要 | 历史收益序列、频率、无风险利率 |
| 了解持有期间从高点跌得有多深 | 需要 | 完整净值序列，或明确期间的最大回撤 |
| 对比基金历史下跌风险 | 需要 | 同一期间和频率的总回报净值或回撤统计 |
| 自定义综合风险调整指标 | 需要 | 几何年化、最大回撤、波动率及样本天数 |

只问收益时不追加风险问卷。只有客户明确要求风险分析或比较下跌风险时，再补充回撤。缺少回撤不能阻塞已经能计算的收益或夏普结果。

## 含义与计算

最大回撤是观察期间内，从此前高点到随后低点的最大跌幅，不等于客户相对买入价的亏损，也不等于年化波动率。逐点累计高点 `peak_t = max(value_0, ..., value_t)`；每点回撤 `value_t / peak_t - 1`；取其中最小值。

当前引擎返回负数，例如 `maxDrawdown: -0.25`；客户语言可写“最大跌幅25%”或“最大回撤-25%”，不要弄反符号。净值从1.20跌到0.90，这段回撤为25%；后来涨回1.30，历史最大回撤仍可能为25%，不会随回本清零。

定义参考 [CFA Institute：Performance Drawdowns in Asset Management](https://rpc.cfainstitute.org/research/cfa-digest/2018/01/dig-v48-n1-3)。这是历史观察值，不代表未来最多只会亏损这些，也不能将它直接从已实现收益中扣掉后称“实际年化”。

## 获取数据与缺口

- 有完整净值序列时，使用 `fund-metrics`，最大回撤来自全部输入点，不经过月末抽样；夏普等指标使用月末序列。该综合入口至少需要三个自然月，不能为满足其要求编造额外数据。更短窗口如需只算回撤，可用确定性工具按上面的逐点公式计算。
- 有完整等间隔总回报收益序列时，AI 可用计算工具依次复投构造路径，再按公式求最大回撤；不能只凭平均收益或夏普值倒推。外部投入/领取不应当作净值涨跌。
- 只有客户提供的最大回撤数字时，补充缺失的观察期间、基金/份额及来源。例如“近一年”与“成立以来”不可直接横比，不把客户当前浮亏当作最大回撤。
- 日度、周度、月度观察值可能给出不同结果；日度也不能保证捕捉盘中跌幅。只有月末值时明确“月度采样最大回撤，可能遗漏月内更深下跌”，不补造日度路径。
- 持有期内最大回撤、基金成立以来最大回撤、购买前历史回撤是不同窗口。说明实际使用窗口；如果客户要求另一个窗口，取得对应路径或保留缺口。

## 自定义综合指标

仅在客户要求此指标时使用 `composite`：

`综合指标 = 目标期限扣赎回费后的几何年化 − |最大回撤| / (样本天数 / 365) − 0.5 × 风险厌恶系数 × 年化波动率²`。

默认风险厌恶系数为2。几何年化、回撤、波动及样本天数应来自一致窗口，说明目标持有期限与赎回费率。只有用户明确给出或核实的费率才能按该费率计算，未知费用不能假装为0。

交付时标为“自定义风险调整指标”，同时保留真实收益率、夏普和回撤的独立含义。这是本项目模型，非行业统一指标、实际年化或未来收益预测，不用它替客户作购买决定。

具体问答和高点/低点示例见 [examples.md](examples.md) 的案例六、七。
