# 对话演示案例

全部数据为假设，用于示范提问及输出格式，不是产品报价、客户资料或真实图片识别结果。以下数值通过附带计算器核对，展示四舍五入至两位小数。执行真实任务时以客户信息重新计算，不照抄答案。JSON 是 AI 内部输入，不展示给客户，除非客户要求。

## 案例一：90天银行理财，只追问费用和期间收支

客户：“我买了10万元理财，90天赚了800元，年化多少？”

AI：“800元是否已扣完费用？期间有没有追加投入或领取？”

客户：“已扣费，没有其他收支。”

AI：“这笔理财的复合折算年化约为 **3.28%**。本金10万元，90天实际赚800元，持有期收益率为0.80%。公式为 `(100800 ÷ 100000)^(365 ÷ 90) − 1`。这是折算值，不代表以后每年都能获得同样收益。”

```json
{"action":"annualized","input":{"initialValue":100000,"endingValue":100800,"days":90}}
```

同一公式的补充示例：客户已明确“投入1万元，90天后收回10300元，已扣费、无中间收支”时，无需提问，直接回答收益300元、持有收益3.00%、复合折算年化 **12.74%**。

## 案例二：基金扣费后收益，不询问回撤

客户：“基金投了5万元，持有180天，卖出后到账53200元，费用全部扣了，没有分红或追加。”

AI：“你的复合折算年化约为 **13.40%**。实际盈利3200元，持有期收益率为6.40%。公式为 `(53200 ÷ 50000)^(365 ÷ 180) − 1`。到账金额已扣费，不再重复扣管理费或赎回费。”

```json
{"action":"annualized","input":{"initialValue":50000,"endingValue":53200,"days":180}}
```

信息已完整，直接计算；不追加最大回撤、波动率或夏普问题。

若客户只说“我买了基金，帮我算收益”，可问：“您投入多少、什么时候买入，扣除赎回费用后能收回多少？如果有定投或中途赎回，也请一并说明。”后续只追问缺失信息。

## 案例三：分两次投入，使用 XIRR

客户：“我分两次投资，一共投了2万元，最后拿回21500元。”

AI：“两次投入分别是多少、在什么日期？最后收回的日期是什么？”

客户：“2025年1月1日投1万元，7月1日再投1万元，2026年1月1日全部收回21500元，没有其他收支。”

AI：“按每笔资金实际投入时间计算，年化收益率 XIRR 约为 **10.05%**。总投入2万元，盈利1500元，累计收益占总投入7.50%；第二笔资金只投入约半年，所以年化需要按现金流时间计算。”

```json
{"action":"xirr","input":{"cashFlows":[{"date":"2025-01-01","amount":-10000},{"date":"2025-07-01","amount":-10000},{"date":"2026-01-01","amount":21500}]}}
```

不把7.50%的总投入收益占比直接称为年化。

## 案例四：保险利益演示表图片，多年度双口径

客户：“每年交1万元，交3年。帮我看第5年和第10年的收益。”客户上传利益演示表图片。

假设图片清晰显示如下数据，AI 先提取、核对表头、单位和行：

| 保单年度末 | 保证退保价值 | 非保证演示退保总利益 |
|---|---:|---:|
| 第5年 | 32,000元 | 35,000元 |
| 第10年 | 38,000元 | 45,000元 |

AI：“按前三个保单年初各缴1万元、对应年度末退保计算，结果如下：”

| 退保时间 | 已缴保费 | 保证收益金额 | 保证年化 | 演示收益金额 | 演示年化 |
|---|---:|---:|---:|---:|---:|
| 第5年末 | 30,000元 | 2,000元 | **1.62%** | 5,000元 | **3.92%** |
| 第10年末 | 30,000元 | 8,000元 | **2.66%** | 15,000元 | **4.60%** |

AI：“未提供真实缴费日期，这里采用每保单年度365天的年度模型 IRR。演示收益不保证实现；若有中途领取，需纳入现金流重新计算。”

```json
{"action":"insurance-table","input":{"annualPremium":10000,"paymentYears":3,"premiumTiming":"year-start","timeBasis":"policy-years","rows":[{"policyYear":5,"guaranteedValue":32000,"illustratedValue":35000},{"policyYear":10,"guaranteedValue":38000,"illustratedValue":45000}]}}
```

单口径补充：客户只说“每年交1万元、交3年，第5年保证退保能拿32000元”，可先给保证年化 **1.62%**，注明年初缴费模型，不要求补出不存在的演示利益。

提前退保补充：第1年末保证退保价值若为6000元，该时点只计已缴的1万元，收益为 **−4000元**，年度模型 IRR 为 **−40.00%**，不能拿完整计划保费3万元作分母。

若演示金额模糊，先给保证结果，集中询问模糊数字或请客户补清晰图；不能猜数、把空格写成0、合并保证和已含保证的演示总利益，或用身故保额代替退保价值。图片处理细节见 [insurance-images.md](insurance-images.md)。

## 案例五：计算夏普比率及波动率

客户：“这只基金2025年每月收益依次是1%、−0.5%、2%、0.5%、−1%、1.5%、0.8%、1.2%、−0.4%、1.8%、0.6%、0.9%，都已经扣了产品费用，也包含分红。帮我算夏普。”

AI：“无风险年利率您有指定值吗？没有的话我按1.50%的假设计算。”

客户：“就按1.50%算。”

AI：“这组样本的历史年化夏普约为 **2.14**，年化波动率约为 **3.22%**。采用2025年12个月收益、每年12期、无风险年利率1.50%的假设，以平均月度超额收益除以月度样本标准差，再乘 `√12`。夏普不带百分号，这个历史结果不代表未来表现。”

```json
{"action":"sharpe","input":{"returns":[0.01,-0.005,0.02,0.005,-0.01,0.015,0.008,0.012,-0.004,0.018,0.006,0.009],"periodsPerYear":12,"riskFreeRate":0.015}}
```

缺序列补充：客户只给案例二的本金、终值和期限，却要求夏普时，先返回年化13.40%，再问是否能提供持有期间净值或日/月收益记录。最大回撤不能补足收益序列，也不能代替标准差。

零波动补充：客户提供12期完全相同的月收益1%，返回“波动率为0，夏普未定义”，不返回无限大，不称没有风险。保险利益表的各年度现金价值也不能直接当作这一类历史收益序列。

## 案例六：风险分析时自动计算最大回撤

客户：“这只基金下面是完整的示例总回报观察值，帮我看这段历史从高点最多跌了多少。”

| 日期 | 总回报值 |
|---|---:|
| 2025-01-31 | 1.00 |
| 2025-02-15 | 1.20 |
| 2025-02-28 | 1.10 |
| 2025-03-15 | 0.90 |
| 2025-03-31 | 1.05 |
| 2025-04-30 | 1.30 |

AI：“这组观察值的最大回撤为 **25.00%**，来自1.20跌到随后0.90：`1 − 0.90/1.20 = 25%`。首尾仍上涨30%，所以最大回撤与相对买入价的收益是不同指标；后来回升到1.30，也不会消除已经发生的历史回撤。”

```json
{"action":"fund-metrics","input":{"history":[{"date":"2025-01-31","value":1},{"date":"2025-02-15","value":1.2},{"date":"2025-02-28","value":1.1},{"date":"2025-03-15","value":0.9},{"date":"2025-03-31","value":1.05},{"date":"2025-04-30","value":1.3}],"riskFreeRate":0.015,"periodsPerYear":12}}
```

有序列就自动计算，不另问“最大回撤是多少”。这里仅能描述已提供观察点；不称已核验真实基金完整日度或盘中路径。

若只有上述四个月末的1.00、1.10、1.05、1.30，则月度采样最大回撤仅为 **4.55%**，会遗漏月内1.20到0.90的下跌。明确采样口径，不能把4.55%称作全路径最大回撤。

## 案例七：客户提供回撤统计，先核对窗口

客户：“A基金回撤10%，B基金回撤8%，是不是B更稳？”

AI：“这两个数对应同一观察期间和采样频率吗，分别是什么份额、来源？”

客户：“A是成立以来，B是近一年。”

AI：“这两个窗口不同，目前不能据此判断谁的历史回撤更小。需要两只基金同一期间、同一频率的总回报净值或回撤统计，再比较下跌深度。历史回撤也不代表未来损失上限。”

客户只关心收益时不触发这段问答；要求自定义综合风险调整指标时才补充回撤、波动、几何年化和样本天数，指标口径见 [drawdown.md](drawdown.md)。
