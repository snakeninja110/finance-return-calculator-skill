# 对话收集信息与公式选择

把用户看作来询问收益的客户，而不是开发者。从现有信息开始，只问会改变计算结果的缺失信息；不要求产品名称、身份证、联系方式或金融账户信息。产品名称可用于定位用户上传的材料，但计算通常不需要这些身份字段。用户更正某个数据后只替换该项并重算，不重启整个访谈。

## 单次投入：基金、理财、国债等

最少需要投入金额、持有天数或起止日期、扣费后收回金额；还需判断期间是否有追加、领取或赎回。客户给“收益300元”时，在确认该收益是否扣费后，AI 将终值整理为本金加收益，不要求客户换算。

只问缺项，例如已有“投入1万元、90天赚300元”时，问：“这300元是否已扣完费用，期间有没有追加投入或领取？”客户明确扣费且无中间现金流，就可内部调用 `annualized`。

以客户确切起止日期相减得到实际天数；不要将任意一个月当成30天或将跨闰年的一年直接当成365天。客户明确给“90天”则直接使用。只有“持有三个月”但无日期时，询问起止日期，或在客户接受近似模型后明确披露天数假设。

使用公式：

- 持有期收益率 = 扣费后的终值 / 本金 − 1。
- 复合折算年化 = (扣费后的终值 / 本金)^(365 / 实际持有天数) − 1。

`annualized` 输出的是复合折算年化，不能标为单利年化或直接与产品宣传的单利年化混称。用户明确要求单利口径时，用计算工具计算“持有期收益率 × 365 / 天数”，并标明“单利折算年化”。

客户只给“产品标注年化2%，投10万”时，年化2%是参考输入而不是已计算的真实收益。先问准备持有多久及到期是否续投，再用 `projected` 算预计金额，结果标为情景。不能凭产品名称推测当前利率。

### 基金费用

客户提供扣费后的实际收回金额时直接计算，不再扣管理费或赎回费。若提供净值/费前金额，收集申购、赎回等实际费用；只有净值比且没有实际费用时标为净值口径，不能称已扣所有费用。

只有客户要求用年化假设估计未来扣费收益时才用 `fund-cost`。不用反问客户“预期年化是多少”来替代实际年化计算。风险、Beta、夏普与自定义 `composite` 仅在客户明确要求时计算，不作为普通收益问答的必填条件。

客户想同时看夏普时，按 [sharpe.md](sharpe.md) 获取历史净值或等间隔收益序列、样本期间及无风险利率。已有序列不重复索取。只给一次买入和卖出金额时，先给年化结果，再问：“夏普还需要持有期间的净值或日/月收益记录，您方便提供这些数据或截图吗？”不能从单笔持有收益反推波动率。

最大回撤按 [drawdown.md](drawdown.md) 判断是否需要：收益、XIRR和夏普计算都不需要询问回撤；客户要求风险分析或自定义综合指标时再处理。已有总回报净值时自动计算，只有现成回撤数字时补充缺失的期间、份额和来源，不用回撤替代波动率。

### 国债

实际收回金额及日期明确时，用单笔收益或现金流公式；有每年付息用 XIRR，不能把历年票息全部挪到期末。客户问票面利率及提前兑取规则下的预计收益时，收集对应公告利率、期限、兑取时间、费率与分档，再用 `savings-bond`。无法核实规则时给出缺口，不猜测。

## 多笔投入或领取：现金流 XIRR

收集每笔投入、追加、领取、赎回的金额与日期，以及目标日期仍持有的可变现金额。已输入的流水不再询问；可接收口述清单或交易截图。真实收支与剩余资产分别保留，避免把已经领取的收益计入期末资产后再算一次。

投入为负，领取与期末变现为正，内部调用 `xirr`。公式为求解：

`Σ[现金流_i / (1 + r)^((日期_i − 首日) / 365)] = 0`。

展示“按现金流时间加权的年化收益率 XIRR”。不能用最终资产/所有投入的简单比值替代 XIRR。多根或无解时说明限制，不随意选一个漂亮的结果。

## 保险：口述或利益演示表图片

先读取已有缴费信息和图片；图片流程见 [insurance-images.md](insurance-images.md)。客户无需手工抄整张表。

最少信息：每次/每年保费、缴费频率及年数、想看第几年、该年度末保证退保价值及可识别的非保证演示退保价值。已知哪项就不问哪项；没有目标年度且图片已有多个清晰年度时可直接计算这些年度。有真实首笔缴费日期就用实际日期 XIRR；没有则采用明确标注的保单年度模型 IRR，不因缺少日期阻塞年度模型。

例如客户说“每年交1万元、交3年，想看第10年的收益”，只需问：“第10年末的保证退保价值和演示退保价值分别是多少？也可以上传利益演示表图片。”如果只给保证金额，先计算保证收益，不强求不存在的演示数据。

等额年初缴费、无中间领取时使用 `insurance-table`，将目标年度终值与此前已经发生的保费现金流配对。客户的缴费时间未明确时，可采用年初模型但须在结果中写明；已明确月缴或年末缴费则使用相应现金流，不覆盖客户信息。目标年度仍处于缴费期时只计已缴期数。

保证/演示分别显示。所谓“预定利率1.75%”“红利实现率100%”都不是保单年化收益率，不能直接作为计算答案。图片中的身故保额不能当作退保收回金额。

## 对话示例与结果格式

完整演示集中在 [examples.md](examples.md)，覆盖银行理财、基金扣费收益、分次投入 XIRR、保险图片双口径、夏普及最大回撤。只参考与当前问题相关的案例，所有数值须以客户数据重新计算。

普通单产品结果用简短文字；多年度保险或多产品比较可用小表格。输出只包含与当前问题有关的指标，不要求客户保存文件、阅读 API 文档或打开网页。
