# 夏普比率问答与计算

夏普比率不带百分号。计算的是每单位波动对应的平均超额收益。历史净值或等间隔收益序列足够时由 AI 调用工具，不要求客户操作脚本。

## 最少输入与提问

- 历史净值（日期、含分红再投资的总回报值）或日/周/月收益率序列。
- 观察频率、样本起止时间和费用口径。收益率写成小数，例如1%为0.01。
- 无风险年利率及其来源/假设。客户没有偏好时可以采用明确标为“计算假设”的1.50%，不当作当前报价；客户指定时使用其值。

缺数据时问一句：“请提供这段时间的日或月收益/净值记录；无风险年利率您有指定值吗？没有的话我按1.50%的假设计算。”已有数据则只问必要缺项。截图需先核对日期、正负号、单位、分红和费用，不根据图形走势猜数值。

现金流导致账户余额跳变时，余额增长不能直接当作投资收益。先用已扣除外部入金/出金影响的产品总回报序列，或取得可信的分期投资收益数据。单次投入终值或保单的逐年度现金价值不是满足该口径的历史收益序列。

## 内部调用

等间隔收益使用 `sharpe`，必填 `returns`（至少两个数值）、`periodsPerYear`、`riskFreeRate`。通常月度为12、周度为52、交易日为252；日度若包含全部自然日则按明确的自然日假设如365处理，不混用。只有两个观测值可以计算，但要说明样本很短；优先使用较完整的历史样本。

```json
{
  "action": "sharpe",
  "provenance": {"source": "演示假设，非真实产品", "frequency": "monthly", "period": "2025-01至2025-12", "riskFreeRateBasis": "1.50%计算假设"},
  "input": {
    "returns": [0.01, -0.005, 0.02, 0.005, -0.01, 0.015, 0.008, 0.012, -0.004, 0.018, 0.006, 0.009],
    "periodsPerYear": 12,
    "riskFreeRate": 0.015
  }
}
```

脚本不验证收益数组对应的实际日期，AI 须先确认同一频率、连续期间，不补零、不把季度缺口当成一个月。有净值时可内部调用 `fund-metrics` 并明确传入 `riskFreeRate`，保持 `periodsPerYear: 12`；该入口抽取月末值。核对连续月份至少三个自然月，各月最后可得观测日期与数据范围必须一致，输出会同时包含月度夏普、年化波动与历史几何年化。

## 公式及展示

设 N 为每年周期数，r_i 为各期简单收益，Rf 为固定无风险年利率：

- 单期无风险收益 `rf = (1 + Rf)^(1/N) - 1`。
- 样本标准差 `s = sqrt(Σ(r_i - 平均r)^2 / (样本数 - 1))`。
- 年化波动率 `s × sqrt(N)`。
- 年化夏普 `(平均r - rf) / s × sqrt(N)`。

固定无风险利率下，超额收益的标准差等于原收益标准差。按每期超额收益计算，不能拿几何年化、单笔折算年化或 XIRR 直接代替平均期收益。年化算术平均 `平均r × N` 仅是历史统计值，不当作未来预期或保证收益。

公式采用常见平方根年化，存在收益自相关时可能不成立。解释和原始定义见 [William F. Sharpe: The Sharpe Ratio (1994)](https://web.stanford.edu/~wfsharpe/art/sr/SR.htm)。此计算入口使用固定无风险利率假设，暂不支持逐期变化的无风险收益序列。

直接回答“历史年化夏普为X、年化波动率为Y%，采用某频率、某样本和某无风险利率”。零波动返回 null，说明“夏普未定义”；短样本披露不稳定性。负夏普可以正常显示，表示该样本平均超额收益为负。不同产品比较保持相同期间、频率、年化因子及费用/无风险利率口径；不设普适优劣阈值，也不用夏普一项作购买结论。

不询问最大回撤作为夏普必填项；相关分工见 [drawdown.md](drawdown.md)，问答案例及夏普2.14的示例见 [examples.md](examples.md) 案例五。
