# 益算 · 理财收益问答 Skill

**算清收益，比较有据。**

益算是一款通过自然语言问答测算理财收益的 AI Skill，覆盖基金、银行理财、储蓄国债、分红险及增额寿险。AI 从已有对话和用户提供的资料中提取投入、期限、现金流与费用，调用计算引擎，直接在聊天中返回持有收益、折算年化及可核对的计算依据。

面向支持 `SKILL.md` 和代码执行的 AI 助手，优先使用 Python 3.9+，也支持 Node.js 18+，无需第三方依赖。支持保险利益演示表图片，图片识别由具备视觉能力的宿主 AI 完成。

## 项目特点

- **自然语言问答**：理解“扣完费赚几个点”“定投实际年化多少”等表达，沿用上下文处理“那 10 年呢”“只看保证的”等续问，只追问缺少的必要信息。
- **覆盖多类产品**：计算基金、银行理财、储蓄国债的持有收益与复合折算年化；需要比较时统一预算与期限，并说明分期投入的资金占用差异。
- **按现金流计算实际年化**：分次投入、追加、领取或赎回使用逐笔现金流 XIRR，明确金额、日期与计算口径。
- **把费用算进收益**：区分净收益与费前毛收益，避免重复扣管理费，单独处理赎回费；费用未知时明确数据缺口。
- **保险保证与演示利益分开算**：从利益演示表图片提取缴费和退保价值，按年度批量计算，区分保证与非保证利益、实际日期 XIRR 与保单年度模型 IRR。
- **按需求分析风险**：根据历史净值或日、周、月收益序列计算夏普比率与年化波动率，按需要计算最大回撤或自定义风险调整指标，并披露观察期与假设。
- **轻量、便于迁移**：整个 Skill 目录可独立复制使用，计算脚本无需联网或第三方库；附七组问答案例及缺失数据、提前退保、零波动等边界说明。

Skill 默认直接在聊天中回答，不制作网页或应用，不要求客户填写 JSON。JSON 和命令行仅供 AI 内部执行。计算依赖用户提供的数据，不自动获取当前产品报价；历史表现和演示利益不代表未来收益承诺。

## 安装与使用

### 一句话安装

复制下面整句发送给 agent（代码块保留完整仓库地址）：

```text
请将 https://github.com/snakeninja110/finance-return-calculator-skill 仓库克隆或下载到当前 AI 的技能目录，文件夹命名为 finance-return-calculator，确保 SKILL.md 位于根目录，优先使用已有 Python 3.9+（无需安装 Node.js），或已有 Node.js 18+，运行仓库中的计算示例验证安装。
```

### 手动安装与使用

已有 **Python 3.9+ 或 Node.js 18+ 任一环境即可**，优先使用 Python。Python 版仅依赖标准库，不需要安装 Node.js、pip 包或其他依赖；Node 版也不需要 npm 包。运行环境由 AI 使用，客户仍只需聊天或上传资料。

将本仓库整个目录复制到目标 AI 的技能目录，目录名使用 `finance-return-calculator`。Codex 可放在 `~/.codex/skills/finance-return-calculator/`。其他支持 `SKILL.md` 的 AI 使用其技能目录约定；没有自动发现能力时，让 AI 读取本目录的 `SKILL.md`。

对 AI 说：

> 帮我算一下理财收益。

安装并启用后，支持自动匹配技能的 AI 可根据中文需求调用。也可以说“算一下这只基金的年化”或“看看这份保险能赚多少”，不必记住英文 Skill 名称。

也支持“扣完费赚几个点”“定投实际年化多少”“算算夏普比例”“从高点跌了多少”“这张保单哪年退不亏”等说法。对话中可直接续问“那10年呢”“只看保证的”“回撤也看看”，AI 会沿用已确认信息并补充必要缺项。匹配规则与容易混淆的表达见[中文触发说明](references/invocation.md)。

保险可以直接附上利益演示表图片，图片读取依赖宿主 AI 的视觉能力。脚本本身只接收识别后的 JSON，不包含 OCR 服务。

## 内部调用示例

使用已有 Python：

```bash
python3 scripts/calculate.py request.json
```

也可使用已有 Node：

```bash
node scripts/calculate.mjs request.json
```

`request.json` 示例：

```json
{"action":"annualized","input":{"initialValue":100000,"endingValue":100800,"days":90}}
```

复合折算年化约3.28%。成功返回 `ok: true`；失败返回 `ok: false` 并以状态码1退出。省略文件参数时读取标准输入。

两个入口使用同一份 JSON 参数，支持全部计算模式。只有 Python 代码工具的 AI 可导入 `scripts/calculate.py` 中的 `calculate(request)`，无需终端命令；没有任何代码执行能力的聊天环境只能收集信息和说明公式，不能完成脚本计算验证。

## 验证

```bash
python3 -B -m unittest discover -s tests -v
```

测试覆盖已知计算结果、XIRR 多解、日期、异常输入，以及移除 Node 路径后运行14个文档示例。环境中也有 Node 时会额外进行两版对照；没有 Node 时该对照项自动跳过，Python 计算仍可独立完成。

## 数据与计算边界

不附带当前产品报价，不会联网下载客户数据。模糊图片数字或缺失费用不补造；演示收益非保证。最大回撤不作为收益或夏普的必填项；只有本金和终值无法计算夏普，零波动时夏普未定义。自定义风险调整指标不等于实际年化收益率。

假设示例经过计算核对。实际图片识别仍须与原图复核，历史表现和情景测算不代表未来收益承诺。
